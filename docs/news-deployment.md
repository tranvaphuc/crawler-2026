# News đã deploy lên SSH_HOST

Đích SSH lấy từ `social-trend/.env` (`SSH_HOST`, `SSH_USER`, `SSH_PASS`). Môi trường Ubuntu 22.04, Node 22 cài riêng ở `/opt/news-flow/node`, không đổi Node của máy. Release hiện tại ở `/opt/news-flow/current`; code chạy dưới user hệ thống `news-flow`.

Service `news-flow.service` chạy **writer ES5**, registry 544 site/13.783 homepage-category seed, lịch quét tối thiểu 5 phút riêng từng publisher, tối đa 112 HTTP task (80 discovery + 32 article) và 3 parser worker bài. Site chỉ nhận lượt tiếp theo khi hết seed pending/running và hết cooldown; không dùng backlog toàn hệ thống để giữ những site còn lại. Một task mỗi publisher, spacing ít nhất 3 giây mỗi host; lỗi 403/429 vẫn pause publisher. Mỗi request tải news có deadline tối đa 2.000 ms từ lúc bắt đầu kết nối đến hết body, gồm proxy CONNECT và TLS, đo độc lập trong worker mạng. Cấu hình thấp hơn được chấp nhận, cấu hình cao hơn bị giới hạn 2.000 ms. Mỗi hop redirect có deadline riêng. Timeout trả `request_deadline_exceeded`, không trả body dở; response hoàn tất sau deadline mạng bị loại. Thời gian chờ queue/cooldown và xử lý HTML được ghi riêng khỏi thời gian mạng. Writer chạy độc lập để chờ ES refresh không chặn lấy bài. Bulk có thời hạn chờ 120 giây; mất phản hồi được đối soát lại qua URL/ID và create409.
